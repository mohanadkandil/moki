# Catalog service implementation handoff

5 November 2026. Implemented only `src/blocks/catalog.ts` and `tests/blocks-catalog.test.ts`, using the real responses retained in this and the sibling `nonseed/` directory. No package edits, full test runs, builds or paid model calls.

Exports:

- `searchParts(query, options?)` returns actual normalized `{lcsc, mpn, manufacturer?, package?, description?, stock?, catalogReceipt}` rows. Indexed jlcsearch is first; HTTP/malformed failures and valid empty indexed results try the verified broader JLCPCB POST. Invalid upstream output is an explicit unavailable error, not a fabricated empty list. No auto-selection or promotion occurs.
- `getPart(lcsc, options?)` matches `CatalogPart`: exact supplier and component/footprint UUID identities, importer MPN/title consistency, actual symbol pins matched to physical pads, raw-response SHA-256, canonical raw geometry SHA-256 and supplied model UUID references. Model URLs are generated only on fixed EasyEDA hosts from validated UUIDs and are never fetched by this service. EP remains visible in SHT40 metadata; removing it belongs to an audited block correction.
- `loadCatalogReceipt(id, options?)` resolves a path-neutral `sha256:<64hex>` identifier and checks its complete content hash plus raw-body hash. Receipts contain schema, capture time, request method/URL/body, HTTP status/content type, truncation flag and exact decoded UTF-8 response body. Store is append-only/content-addressed; mutable cache indexes point to receipts and cannot supply fabricated part objects.
- `CatalogOptions` supports isolated `cacheDir`/`fetch`, timeout, streaming byte limit, result limit and maximum cache age. Defaults: `MOKI_BLOCK_PARTS_DIR` or `var/block-parts`, 10 seconds/request, 4 MiB/response, 8 results, 24-hour cache. Configured age cannot exceed seven days. Capture time remains in the immutable receipt; cached stock is not represented as fresh permanent inventory.

`footprintSha256` is SHA-256 of recursively sorted-key JSON for the exact importer `packageDetail.dataStr`, preserving array/shape order. It is **not** the hash of converted tscircuit/CJ geometry. EDA conversion remains separate. `rawSha256` hashes the full cached importer HTTP JSON body, including its wrapper.

## Explicit standard/KiCad fallback contract

Latest extension: `CatalogOptions.allowMetadataOnly` defaults true; false retains strict imported-geometry behavior. Metadata-only output is allowed only after an actual fixed importer endpoint returns an untruncated404, or a200 component has validated supplier IDs, UUID/MPN/symbol identity and explicitly missing package geometry. Malformed JSON/IDs/UUIDs/pin maps, footprint parse errors, HTTP403/500/503 and truncated responses do not authorize fallback. An exact-ID JLC POST must supply exactly one matching code and nonempty MPN; when the importer supplied an MPN it must agree. Supplier metadata is tagged `importer:'jlcpcb-metadata-only'`, `pins:[]`, `footprintSha256:''`, `models:[]`; its main receipt/raw hash identify the actual supplier response. `importerUnavailableReceipt` separately identifies the captured importer absence. Absence is not cached as an imported part, so later calls retry the importer. Stock/datasheet metadata may reuse the existing bounded supplier snapshot cache.

Renderer entrypoint `ensurePart(BlockPart,CatalogPart)` first resolves immutable supplier receipts and verifies identity/hash/pin metadata. Ordinary importer-backed parts retain `ensureImportedPart`. Metadata-only parts require an explicit cited standard or KiCad footprint, physical pinout marked verified, complete unique positive numeric pad mapping, and independently reviewed datasheet pages. This function never takes model-authored TSX or arbitrary footprint URLs. Existing full-importer parts can also choose an explicitly cited alternate standard footprint; actual imported pad identities must agree.

Footprinter resolves through installed `@tscircuit/footprinter`, bounds generator parameters/geometry and checks declared numbers against actual generated copper-pad hints. KiCad IDs use `kicad:Library/Name` (also Library:Name); the citation must name the exact derived official KiCad GitHub/GitLab raw URL and pin its complete bytes by SHA-256. No redirects/model URLs are followed. The already installed converter resolves real numeric pads. Unsupported model `(at...)` syntax in a legacy official footprint required excluding only complete balanced `(model ...)` expressions before conversion; original raw bytes/hash remain in the audit. No pad geometry is removed by that workaround and no imported3D model is claimed.

Fallback returns a chip component with verified numeric native aliases and trusted resolved footprint geometry, plus source/id, actual tool version, resolved geometry hash and an immutable audit path under the catalog store's `footprints/`. The KiCad audit preserves full original source bytes. Every declaration still needs independent schematic review, native rendering/DRC and block-test actual-pad attestation before acceptance. Fallback corrections/omitted pads and alphanumeric physical numbering are explicitly unsupported in this bounded slice and fail closed. Existing importer pad-correction behavior remains separate.

Imported executable assets now live in immutable `eda/blocks/parts/<lcsc>/<footprintSha256>/` directories. Generated module filenames also include actual TSX content SHA, preventing one process from reusing a module for another geometry or changed generated-symbol revision. Raw captures and manifests are immutable; manifests include full catalog receipt identity. Legacy spike directories/files remain untouched. A constant React value import makes trusted generated modules work with both Node classic JSX tests and Bun. The regression generates two deliberately synthetic geometry revisions of a real retained supplier response, checks different returned pad widths and reuses the first component only for its own identity; no supplier claim is made for the synthetic revision.
