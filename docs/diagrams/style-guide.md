# Moki architecture diagram style

Source: `web/src/style.css` and `web/src/brand.tsx`.

| Role | Value |
| --- | --- |
| paper | `#f8f7f3` |
| paper-2, for zones | `#f0efea` |
| ink | `#252525` |
| muted text | `#5f5f58` |
| rule | `#d9d9d0` |
| accent | `#139df2` |
| accent-tint | `#eaf5fd` |
| connector | `#6f6f69` |
| type | Manrope, embedded in the SVG and HTML |

- **Size for GitHub.** The canvas is 1200 units wide and the README shows it about 830 px wide, so nothing goes below 16 units.
- **One accent.** Blue marks the shared plan, the one idea the drawing is about.
- **Dashed means proposed.** Each dashed box or arrow also says "proposed" in words.
- **Quiet logos.** Simple Icons marks stay single-colour in ink, at their original proportions. The tscircuit icon is the official PNG, unmodified. ngspice has no published mark, so it gets a plain waveform that isn't presented as a logo.
- **No decoration.** No shadows, gradients, italics, eyebrows or background motifs.
