# Isolated board toolchain

Use Bun (`/home/sogo/.bun/bin/bun` on this VPS). All direct versions in package.json are exact; bun.lock fixes transitive resolution. Run `bun install --frozen-lockfile` inside eda/ to reproduce the toolchain. Root npm installs intentionally do not resolve this package.

`bun eda/render.ts --job /absolute/job/dir` reads board.tsx and writes circuit.json, schematic.svg, pcb.svg, board.glb, gerbers.zip, bom.csv, pnp.csv and receipt.json. Source must default-export a function returning a tscircuit board; optional exported boardMetadata is persisted for mechanics. JSX and bare imports resolve in eda/node_modules after Bun transpilation. User source executes only in this worker; subprocess separation is not an OS permissions sandbox.

Exit 0 means artifacts generated with no reported DRC errors; exit 2 means artifacts generated with DRC errors preserved in receipt.json; exit 1 means a worker failure with render-error.json. Warnings remain visible. SVGs are generated by circuit-to-svg with a responsive viewBox added. Fab files use the official tscircuit converters, including Excellon drill files in the Gerber ZIP.

Timings are measured with performance.now(). `render` is initial synchronous graph/layout work (including starting asynchronous routing); `route` is renderUntilSettled, including autorouter completion and remaining asynchronous work. Total includes subprocess/import overhead. The API adds mechanical and firmware stages. Cached EDA stages show real copy time plus skipped reused stages, never the original execution duration.

Footprints translate catalog physical pin coordinates verbatim to +Y-up PCB coordinates. They remain unverified physical prototypes: the catalog itself labels geometry approximate. Module variants and all pin spacings must be confirmed against actual parts before fabrication. Module/socket 3D models are illustrative JSCAD solids rather than manufacturer CAD. No hardware fabrication or operation is inferred from a zero-error software DRC result.

Board and enclosure module previews share `eda/enclosure/module-preview.ts` and `module-mech.ts`, so socket/spacer heights and encoder/USB/display locations agree. API jobs mark DRC `checked: false` until the worker has produced a DRC receipt. Bench cold runs isolate the mechanical cache in each job as well as bypassing EDA reuse; warm/cached jobs can reuse the wrapper's separately reported mechanical cache.
