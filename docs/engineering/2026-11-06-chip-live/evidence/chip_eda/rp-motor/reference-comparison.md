# Owner's RP2040 reference: inspection and comparison

Inspected 2026-11-06, read-only. Exact reference: [imrishabh18/rp2040-motor-controller](https://tscircuit.com/imrishabh18/rp2040-motor-controller#3d), version **1.0.48**, release **bc93e130-7357-4352-a45f-c9cf65563446**. Reviewed source, published PCB SVG, controller/programming/motor-driver schematic SVGs, and both published 3D PNGs. This was image/source inspection, not an interactive bottom-side 3D inspection or a powered-hardware test. No reference source, routes or CAD assets were incorporated into Moki.

| | Reference | Accepted Moki job |
|---|---|---|
| Purpose | NEMA17 **stepper**, DRV8825, separate programming and USB-PD motor-power ports | **DC motor**, DRV8833, RP2040 minimal core |
| Layout | Four layers, compact shaped outline, four mounting holes | Two layers, 100 × 80 mm, 42 parts, 118 traces, 81 vias |
| Routing | Saved geometry-specific route, with explicit clock paths | Fresh native automatic routing, including a bounded clock phase |

The reference's extra PD, winding-current sensing, temperature telemetry and optional encoder are different requirements. Its README declares license **unset**, no included firmware, and powered hardware untested. The default 5 V PD state must be raised before operating its DRV8825. These are author declarations, not independently repeated tests. [Reference description and limitations](https://tscircuit.com/imrishabh18/rp2040-motor-controller/blob/README.md).

**Clock and schematic.** The reference separates RP2040/power, programming USB/QSPI, motor driver and motor power into named sheets. Its clock components have explicit local placements: Y1 at (-1.2, -6), rotation 270°; 15 pF capacitors at (-2, -9.8) and (0, -9.8); 1 kΩ XOUT resistor at (1.8, -5.8). Clock traces specify zero vias and several explicit `pcbPath`/straight-line paths. This is useful evidence for keeping the oscillator local; it is not evidence that unrestricted routing automatically discovered those paths. [RP2040 implementation](https://tscircuit.com/imrishabh18/rp2040-motor-controller/blob/vendor/rp2040.js), [sheet definitions](https://tscircuit.com/imrishabh18/rp2040-motor-controller/blob/schematic/SchematicSheets.tsx).

**Routing and ground.** The entry loads `savedRouting`; its adapter checks the complete normalized input against `route-plan.json`, then returns stored traces. The README identifies Freerouting plus subsequent checked repairs as its route provenance. The entry has top/bottom GND pours; separate inner-layer pours spread heat from the imported driver's twelve exposed-pad thermal vias. Crucially, it explicitly sets **`placementDrcChecksDisabled`**, with a via-in-pad explanation, despite broader README language about checks remaining enabled. Other claimed independent checks do not erase this flag. Moki must retain its own placement/native DRC gates and built-in routing policy. [Entry](https://tscircuit.com/imrishabh18/rp2040-motor-controller/blob/index.circuit.tsx), [saved-route adapter](https://tscircuit.com/imrishabh18/rp2040-motor-controller/blob/routing/saved-routing.ts), [thermal copper](https://tscircuit.com/imrishabh18/rp2040-motor-controller/blob/schematic/Drv8825ThermalCopper.tsx).

**Visuals/models.** The PCB preview visibly places two USB sockets on one edge, motor connector on another, MCU and crystal locally, with dense copper and four mounting holes. The published 3D view shows shaped component bodies, metal USB shells, connector, buzzer and populated passives on green solder mask. RP2040 source supplies actual EasyEDA OBJ/STEP URLs; the README discloses a same-package substitute CAD model for one bulk capacitor. Thus a polished preview is not proof that every body is an exact part model. [Pinned PCB](https://api.tscircuit.com/package_files/view?package_release_id=bc93e130-7357-4352-a45f-c9cf65563446&file_path=dist%2Findex%2Fpcb.svg), [pinned 3D](https://api.tscircuit.com/package_files/view?package_release_id=bc93e130-7357-4352-a45f-c9cf65563446&file_path=dist%2F3d-whitebg.png).

**Moki evidence and remaining delivery.** Job **193f6a73-452d-4124-9785-0a14940322b0** uses RP core revision 4 and motor revision 2. Its artifacts confirm the table counts and 42 CAD records; CAD-record presence alone does not prove successful model rendering. Native DRC, strict source-netlist correspondence, Gerber-derived all-layer shorts, schematic placement and sandbox firmware compile passed. Clock paths measured 9.8943 / 2.2717 / 5.6402 mm with zero vias. Six routing-style warnings remain; a native cleanup candidate failed validation and was discarded. This is not manufacturing or powered-motor qualification.
