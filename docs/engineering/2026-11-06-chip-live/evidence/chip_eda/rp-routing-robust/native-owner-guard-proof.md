# Private pinned native owner guard

The isolated helper pins SDK0.0.1037 and upstream bundle SHA `9424629c…47f6fa`, replaces exactly one source-inference predicate, and prepares an immutable private ESM copy. Explicitly owned copper may contribute aliases only to a matching declared connection; the old geometry fallback remains only for unowned obstacles. Pathfinding, generated copper and clearance rules are not changed. Installed SDK files are never written.

The copy relocates the original relative chunk and bare dependency imports to their original file URLs. Unconditional package-entry checks prevent `require` resolution from silently selecting a different ESM conditional entry. Audit output includes upstream, predicate-patched, loaded-module and helper hashes plus dependency paths/hashes. Only the public Pipeline9 constructor is exposed, and loading does not instantiate it. The caller must enable this solely through its private diagnostic flag.
