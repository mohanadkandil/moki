# Independent native width-refinement review

Reviewed the coordinator's `eda/blocks/native-width.ts` and `router.ts` integration against the installed primary implementation/declarations in `@tscircuit/capacity-autorouter` 0.0.1037 and core 0.0.2266. No native routing, render or width expansion was run by this reviewer.

The pinned public pipeline exposes `pipelineDef`, its named `powerTraceExpansionSolver` constructor and the `PowerTraceExpanderOptions` contract. The native pipeline uses that same constructor with `onlyConnectionNames` and `allowNewVias:false`; its default selection omits nominal 0.15 mm nets. The added replay selects all original connection names first, then only residual subminimum net names at the existing fabrication clearances. There is no custom pathfinder or wrapper point/width edit.

The retained actual 134193af routing input contains 27 connections, 423 obstacles, zero input traces and no fixedTraces array. Its fixed clock/escape copper is encoded in obstacles, which both replay passes preserve along with connections and the board minimum width. The stage's selected names are expansion targets, not a promise that every other routed net is immutable: native blocker moves are possible. The wrapper returns the native output verbatim. Fresh core materialization is required because actual native refinement can move existing via geometry. Every final physical/source/copper check remains necessary; a width-stage result alone is not board acceptance.

Two review findings were corrected by the coordinator: the adapter test harness needed its new dependency, and cancellation could bypass the stop callback when a stage started solved. The helper now checks cancellation before construction and after the native loop; the adapter checks cancellation after awaited width evidence and before publishing completed output.

Added six fake-native-stage regressions in `tests/blocks-native-width.test.ts`. They cover two-pass residual-only selection, retained fixed obstacles and clearances, unchanged input, verbatim native geometry return, persistent subminimum width, original native failure, cancellation before an already-solved stage and during either a pending or final solved step, the per-stage 90-second budget, missing pinned stage, invalid margin and nonfinite width rejection. These tests instantiate no native solver. Together with the coordinator's six adapter regressions, all 12 pass; strict targeted TypeScript passes. Logs: `native-width-review-tests.tap`, `native-width-review-typecheck.log`.

No remaining blocker found within this reviewed adapter/refinement scope. Coverage excludes whole-board native refinement, regenerated pours, all-layer Gerber shorts and full job acceptance, which the coordinator runs separately. The existing source helper keeps its exact width floor, and the new independent whole-Circuit-JSON width guard closes the installed official checker's one-port-to-net gap.
