# Product context — Moki repository, public rename pending

The product helps curious makers turn a described physical object into understandable electronics and, later, a fitted body and working device. The initial user is a software-comfortable maker who needs help with electronics. They need to see what connects to what and change the idea without losing the relationship between the circuit and its physical arrangement.

Current sprint: compare three distinctive, lovable identities and their landing/workbench screens, then implement a bounded prompt → schematic → circuit-view workflow. Existing AI/Daytona CAD/film flows are preserved. A constrained graph preview is not a fabricated board, an ERC pass, an electrical simulation or verified hardware. Unsupported prompts must be explained honestly.

A successful first experience: type a supported idea, see the components and nets, switch to a physical view of those same components, inspect a connection, revise the prompt, and retain accurate limitations. Keep the task calm and usable, with an expressive, original brand and a warm competent character. Name/mascot/direction selections remain provisional. No invented customer quotes, metrics or manufacturing-readiness claims.

Platforms: desktop web workbench plus useful responsive narrow layout. Stack: existing strict TypeScript, React and Vite. No framework migration. Preserve user work and previous source paths. No automatic commit/push/publication or contacting people.
